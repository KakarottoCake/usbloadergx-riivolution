# Hardware package: in-place control, then grown T0 (SB4E01 only)

T0 establishes launch integration, not consumption of added mod files:
its files are never opened by the game. Launch 1 must pass before
launch 2 means anything.

## Loader install
Back up the existing `apps/usbloader_gx` dir on SD first, then install
this build's `apps/usbloader_gx` (`boot.dol` hash above). The card log
of each test launch must contain the new marker lines named below,
which no older build emits.

## SD mod pack (same card layout both launches)
Base: the existing `/riivolution/gxdiag/` pack (T0 `a.bin` + `b.bin`,
`gxdiag.xml`).
For launch 2 only, add 150 generated files plus one choice (exact):
- On a PC, in `/riivolution/gxdiag/T8/`, generate 150 files
  `grown0000.bin` … `grown0149.bin` (64 bytes each; content arbitrary -
  the game never opens them).
- In `gxdiag.xml`, inside the existing Test option's choices, add:
  `<choice name="P1 T8 Grown"><patch id="gx_t8"/></choice>`
  and beside the other patch definitions add:
  `<patch id="gx_t8" root="/riivolution/gxdiag">`
  `  <folder disc="/GXDiagBig" external="T8" create="true" recursive="true"/>`
  `</patch>`
- Expected table (production builder, verified): plain ≈164284,
  compacted ≈154673 - grown by ~881 bytes even compacted, so the grown
  apploader path runs rather than compaction. Fragment budget: ~152
  files, far below the 20000 shared cap.

## Launch 1 — in-place control ("P1 T0 Creates")
Must all appear: `early FST : agrees`, `one plan, both phases`,
`compacted table ... STAGED`, `fits in the room the apploader already
set aside`, `OUTCOME: FST_STAGED`. Must NOT appear: any `WITHHELD`
line, `EARLY_LATE_DIFF`. Expected outcome: normal boot.

## Launch 2 — grown T0-big ("P1 T8 Grown")
Must all appear: `early FST : agrees`, `virtual header serves grown
size/max`, `installs at the apploader-reported base`,
apploader-reported base/size lines, staged size ≈164284,
`OUTCOME: FST_STAGED`. Must NOT appear: `compacted table ... STAGED`,
`fits in the room`.
- On success additionally: `grown table apploader-owned at ...
  verified, no rewrite`. Expected outcome: unknown - that is the
  experiment.
- On mismatch instead: loader return with blink 4 (bytes) or 5
  (words/arena) plus `grown table NOT apploader-owned ... refusing
  the launch, no repair`. That is a valid experimental result, not a
  tester error: preserve the log and the blink code.

## If launch 2 does not boot
STOP after these two launches (maximum). Preserve the complete card
log (`/riivolution/usbloadergx_riivo_SB4E01.log` on the mod device),
the blink code if any (loader return), and the observed outcome
(title / black screen / loader return) with no interpretation beyond
observables. A later milestone (real grown mod with memory patches,
e.g. Spectral) follows only after launch 2 boots.

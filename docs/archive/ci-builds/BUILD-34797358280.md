## Reporting corrections (applied here, not back-edited into the build)
- Without explicit cache publication, acknowledgment visibility is **not
  guaranteed** - rather than "invisible by construction." A stale line
  that happens to leave the cache (incidental eviction) must not count
  as a supported protocol path; only the cleaned ack word, observed
  post-init for the installed epoch, gates the commit. An ack observed
  without the sync hook in play would be evidence of luck, not of the
  protocol, and the probe treats it as such (content match is still
  required alongside).
- Lowering the arena word is this design's **reservation attempt** - not
  an established necessary or sufficient condition for survival. It is
  the mechanism by which the loader asks the game to avoid the region;
  whether startup honors it, and what else writes there, is exactly the
  open question below.

## Remaining blockers (unchanged in kind)
The next compatibility blocker is **where the runtime module and data
can reliably survive game startup**: the lowered-arena reservation, the
Table/store bytes across apploader/DOL/BSS startup traffic, and the
game's actual heap behavior - none observed yet. More activation tests
alone will not resolve that; it needs a hardware round instrumented for
reservation survival (pre-jump vs post-startup reads of the region),
not another T0-only launch. DVD9 refusal and the sync-less-console
darkness (MODACK withhold by design) stand alongside.
